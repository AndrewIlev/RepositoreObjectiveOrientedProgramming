### 3. Висновок

Покриття рядків показує, чи виконувався код, а покриття розгалужень — чи
перевірені всі напрямки умов. Coverage не гарантує правильність тестів:
виклик функції без `assert` може виконати ті самі рядки, але не перевірити
результат. У фінальних тестах значення `get_angles` перевіряється твердженнями.

Для точки входу в `app.py` використано `pragma: no cover`, оскільки друк
демонстраційного повідомлення не є логікою класу `Figure`. Мінімальний поріг
покриття становить 90%; GitHub Actions перевіряє його під час push і pull
request.

HTML-звіт призначений для перегляду в браузері, XML — для CI та інших
інструментів. Згенеровані звіти й кеші не додаються до репозиторію.
